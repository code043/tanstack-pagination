# Tanstack Pagination

Paginação com TanstackQuery
### Requirements

- Vscode
- Node
- Next.js

### Installation

```bash
git clone https://github.com/code043/tanstack-pagination.git
cd tanstack-pagination
npm install
npm run start
```
